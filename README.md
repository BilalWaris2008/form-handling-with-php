# 🔐 PHP Login & Registration System

A simple and secure **PHP & MySQL Login & Registration System** that allows users to register, log in, update their information, and manage user records. This project was built to practice PHP backend development, MySQL database operations, and user authentication.

- 🔐 User Login Authentication
